# 삼천당제약 (SamCheonDang Pharm) 메인 홈페이지 현대화 리디자인

**삼천당제약(http://www.scd.co.kr/)**의 메인 웹페이지를 2026년 최신 웹 표준 및 바이오/제약 기업 스타일에 맞추어 반응형(Responsive Web & Mobile)으로 전면 재설계한 프로젝트입니다.

---

## 🌟 주요 특징 및 현대화 개선 사항

### 1. 반응형 디자인 (Mobile & Tablet & Desktop 가변 적용)
- **모바일/태블릿/데스크톱 대응**: 미디어 쿼리 및 Flex/CSS Grid 기반으로 화면 크기에 따라 최적의 레이아웃을 자동 제공합니다.
- **모바일 드로어 내비게이션**: 햄버거 메뉴를 통한 직관적인 전체 메뉴 탐색 지원.

### 2. 최신 제약/바이오 트렌드 UI/UX
- **모던 비주얼 & 타이포그래피**: 프리텐다드(Pretendard) 서체, 글래스모피즘(Glassmorphism), 마이크로 인터랙션 및 부드러운 스크롤 애니메이션 적용.
- **다크 모드 / 라이트 모드 지원**: 상단 유틸리티 바의 테마 버튼으로 손쉽게 전환 가능하며, `localStorage`에 상태가 보존됩니다.

### 3. 풍부한 원본 리소스 및 데이터 연동
- **오리지널 리소스 100% 로컬 연동**: 삼천당제약 원본 사이트의 기업 로고, 메인 비주얼, 공장/연구소 시설 사진, 25개 주요 의약품 고해상도 이미지를 `images/` 폴더에 완비하여 오프라인 환경에서도 원활하게 동작합니다.
- **인터랙티브 제품 쇼케이스**: 
  - 카테고리별 탭 필터링 (전체, 안과용제, 순환기/내분비, 소화기/일반의약품).
  - 실시간 검색 기능 (제품명, 성분명 즉시 검색).
  - 제품 카드 클릭 시 효능·효과, 용법·용량, 성분·함량, 포장단위를 보여주는 퀵뷰(Quick View) 모달 팝업 제공.
- **빠른 단축키 검색 (`Ctrl+K`)**: 키보드 단축키 또는 상단 검색 버튼으로 즉시 원하는 의약품을 검색할 수 있는 모달 지원.

### 4. 기업 핵심 가치 & 서비스 섹션
- **기업 성과 카운터**: 1943년 창립 80+년 전통, 국내 1위 안과 점안제 전문성, 글로벌 EU-GMP/cGMP 무균생산 인증 등 뷰포트 진입 시 애니메이션 카운트.
- **R&D & 글로벌 스마트 팩토리**: 향남 무균 점안제 자동화 라인, 중앙연구소, 아일리아 바이오시밀러 글로벌 파이프라인 소개.
- **실시간 소식 & IR 센터**: 주가 시세 정보 위젯, 최신 보도자료/공시 목록, 재무정보 바로가기.
- **원클릭 고객 서비스**: 내 주변 약국 찾기, 1:1 제품문의, 사이버 신문고, 인재 채용 안내.

## 📁 폴더 및 파일 구조

```
\scd_main\
├── index.html              # 현대화된 메인 홈페이지 HTML5
├── css/
│   └── style.css           # 반응형 디자인 시스템, 테마 및 애니메이션 CSS
├── js/
│   └── main.js             # 슬라이더, 검색, 모달, 테마 등 인터랙티브 스크립트
├── data/
│   ├── products.json       # 삼천당제약 25개 주요 제품 상세 데이터
│   ├── news.json           # 최신 소식 및 보도자료 데이터
│   ├── company_info.json   # 기업 개요 및 기본 정보
│   ├── menu.json           # 전체 사이트 메뉴 구조 트리
│   └── site_data.json      # 통합 사이트 메타데이터
├── images/                 # 로고, 제품, 공장, 연구소 등 118+개 이미지 에셋
└── README.md               # 프로젝트 안내 및 가이드 문서
```

---

## 🚀 실행 방법

1. 브라우저에서 `.\scd_main\index.html` 파일을 직접 열람합니다.
2. 별도의 웹서버 없이도 모든 인터랙티브 기능(슬라이더, 검색, 모달, 테마 전환 등)이 정상 작동합니다.
